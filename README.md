# SS14 Utility

Пара небольших независимых утилит для Space Station 14. Общего кода между ними нет — это просто
один репозиторий на двоих, каждая утилита живёт в своей папке со своим README и лицензией.

## [SS14fyImage](SS14fyImage/)

PyQt6 GUI/CLI-инструмент, который превращает фото в SS14 rich-text «картинку» (текст, который в игре
выглядит как изображение).

## [SS14MidiPlayer](SS14MidiPlayer/)

Настольный MIDI-плеер (.NET/WinForms), который звучит так же, как инструменты в билде
[dead-space-server/space-station-14-soyuz](https://github.com/dead-space-server/space-station-14-soyuz) —
тот же синтезатор, те же саундфонты и портированная логика инструментов игры. Позволяет слушать и
подбирать миди, не заходя в игру, включая симуляцию сетевых лимитов сервера.
